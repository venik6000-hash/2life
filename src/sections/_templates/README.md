# Section Template

Этот шаблон нужен для единообразия новых секций:

1. Локальное состояние и side-effects живут в `useSectionState.js`.
2. JSX и рендер остаются в `SectionTemplate.jsx`.
3. Внешние пропсы секции должны быть минимальными и явными.

Используй эти файлы как заготовку при создании новой секции.
